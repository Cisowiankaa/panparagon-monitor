# PanParagon Monitor

Webowa aplikacja do analizy liczby paragonów z eksportu CSV PanParagon.

## Funkcje
- liczba paragonów w miesiącu,
- ranking sklepów,
- widok miesięcy,
- import CSV,
- lokalne przechowywanie danych,
- generator raportu do Slacka,
- działanie bez AI.

Kwoty zakupów nie są analizowane.
